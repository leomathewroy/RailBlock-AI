# RailBlock AI
### AI-Powered Automatic Block Planning to Maximize Asset Availability for Train Operations on Indian Railways

---

> **Important Operational Disclaimer:**
> **This project is a decision-support prototype and does not directly control railway infrastructure or operational signaling systems.**
> All schedules and recommendations generated by the system are decision-support recommendations and require validation and approval by authorized Indian Railways traffic controllers and sectional engineers before operational use.

---

## 1. Project Overview

**RailBlock AI** solves the complex challenge of railway maintenance block planning on high-density corridors of Indian Railways. Maintenance blocks (track, electrical overhead catenary, and signalling) are essential for safety and infrastructure longevity, but poorly coordinated possessions lead to severe train delays, rolling stock idling, and high operational costs.

RailBlock AI combines:
1. **Public Timetable & Route Datasets** (Indian Railways 5,208 trains, 8,990 stations, 400K+ schedules)
2. **Machine Learning Predictive Layer** (XGBoost Regressor for section delay forecasting with $R^2 = 0.9024$, $MAE = 3.52\text{ min}$)
3. **Operations Research Engine** (Google OR-Tools CP-SAT solver for conflict-free maintenance window scheduling)
4. **Railway Operations Control Center Web Interface** (React, Framer Motion, and Plotly Gantt visualizations with What-If sensitivity simulation)

## 3. Technology Stack

### Frontend:
- **Framework**: React 18, Vite
- **Routing**: React Router DOM v6
- **Animations**: Framer Motion (GPU-optimized scroll tracking with `prefers-reduced-motion` compliance)
- **Visualizations**: Plotly.js / React-Plotly (Interactive Gantt schedules, donut asset gauges, delay trends)
- **Icons**: Lucide React
- **HTTP Client**: Axios with Bearer token interceptor

### Backend:
- **Web Framework**: FastAPI 0.100+
- **ASGI Server**: Uvicorn
- **Database ORM**: SQLAlchemy 2.0 (Asyncio) with `asyncpg` and `aiosqlite` auto-detection fallback
- **Schema Validation**: Pydantic v2
- **Authentication**: JWT (JSON Web Tokens) with direct `bcrypt` password hashing
- **Security**: Strict CORS origins, nosniff, frameguard, XSS protection, input shielding

### AI / ML & Optimization:
- **Delay Prediction**: XGBoost Regressor (`n_estimators=120`, `learning_rate=0.08`) + Scikit-Learn baseline fallback
- **Optimization**: Google OR-Tools (Constraint Programming CP-SAT Solver) with cumulative capacity constraints and non-overlapping interval constraints

## 5. Environment Configuration

Copy `.env.example` to `.env` in the root and backend directory:

```bash
cp .env.example .env
```

Key environment variables:
| Variable | Description | Default |
|---|---|---|
| `DATABASE_URL` | PostgreSQL async connection URI | `postgresql+asyncpg://railblock:changeme@localhost:5432/railblock_ai` |
| `SECRET_KEY` | Application encryption secret | (Set in `.env`) |
| `JWT_SECRET` | Secret key for JWT signing | (Set in `.env`) |
| `JWT_ALGORITHM` | JWT signing algorithm | `HS256` |
| `DEMO_USERNAME` | Chief Controller demo login | `Novaa_x` |
| `DEMO_PASSWORD` | Demo account password | `RailBlock@2026` |
| `CORS_ORIGINS` | Comma-separated allowed origins | `http://localhost:5173,http://localhost:3000` |
| `MODEL_PATH` | Directory with trained model | `ml_models/delay_model` |

## 6. Local Setup and Execution

### Prerequisites:
- Python 3.10+
- Node.js 18+ and npm

### 1. Backend Setup:
```powershell
cd d:\Smart\RailBlock-AI\backend

# Create and activate virtual environment
python -m venv venv
.\venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run data validation, preprocessing, and ML model training
python scripts/validate_datasets.py
python scripts/preprocess_datasets.py
python scripts/generate_synthetic_data.py
python scripts/train_model.py

# Seed database (users, stations, trains, corridors, assets)
python scripts/seed_database.py

# Run test suite
pytest -v

# Start FastAPI server
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 2. Frontend Setup:
```powershell
cd d:\Smart\RailBlock-AI\frontend

# Install dependencies
npm install

# Build for production verification
npm run build

# Start Vite development server
npm run dev
```

Visit `http://localhost:5173` in your browser.
